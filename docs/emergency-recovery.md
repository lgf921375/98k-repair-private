## 在其他 Linux 环境恢复（仅说明，不要未经审查运行）

安装 `gpg`、`zstd`、`tar` 后，将加密包、密钥和 SHA256 文件放到单独目录。

```bash
sha256sum -c 98k-core-recovery-20261017.sha256
gpg --batch --pinentry-mode loopback --passphrase-file recovery-key.txt \
  --decrypt 98k-core-recovery-20261017.tar.zst.gpg | zstd -dc | tar -tf - | head
```

确认清单正常后，在**隔离且授权**的环境还原。不要在正式服务器上直接覆盖原有数据。

## 失去远程终端之后

- 本 GitHub 仓库可继续用于更新代码、文档及 GitHub Actions 语法检查，但不会因此自动连接到原服务器。
- 原服务器私有文件库若仍可访问，可从手机浏览器登录、下载归档；这不依赖 Remote Desktop Commander 额度。
- 可以在手机 Termux 中运行 ADB 采集客户端日志，但仍不能直接确认 M2 认证分支。
- 若服务器或文件库也不可访问、且事前没有把加密包和密钥取到设备外，则此仓库不足以恢复完整项目。
