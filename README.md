# 98K 传奇 Android APP 修复研究（公开脱敏镜像）

> 状态：**修复尚未完成**。当前公开仓库只存放可审查的修复辅助脚本、证据摘要和交接；**不是完整游戏源码，也不是可直接构建的成品**。

## 修复目标

调查 ARM32 Android 客户端 `com.gom.asp2` 选择角色后黑屏、服务端返回 `528` 的问题，尽可能复用既有程序，保留原账号、角色、怪物和地图规则。

## 已确认的结果

| 项目 | 结论 |
| --- | --- |
| Android APK 重打包、ZIP CRC、v2/v3 签名校验 | 通过（历史候选的静态/构建验证） |
| 真实安卓发送六段 `RunLogin`、携带 32 字符 HWID | 通过（真实手机抓包摘要） |
| 手机端账号与 admission session 一致 | 通过（仅一致性，不代表数值合法） |
| 修复后进地图 | **失败**：仍收到 `528` |
| session 数值是否满足服务端 `>= 2` | **未覆盖**：只保存一位数字长度，未取得具体数值 |
| PC 自动化选服 | **未通过**：按钮坐标已调整，但仍停留“加载中” |
| 容量、长期稳定性及多人同时在线 | **未覆盖** |

原安卓客户端最初只发送五段 `RunLogin`；测试版已补齐第六段 HWID，但 **528 仍然存在**，因此不能把缺少 HWID 当作唯一根因。
