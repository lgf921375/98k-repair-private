# 98K 研发脚本（历史原样留档）

下面的 Python 文件来自隔离项目服务器，经检查未嵌入凭据后，作为研究资产上传到公开仓库。文件仍使用原项目绝对路径，因此**不能在 GitHub Actions 上直接运行**，也不应在未经审核的正式服务上运行。

| 文件 | 作用 | 状态 |
|---|---|---|
| `build_runlogin_hwid_test_20261016.py` | 将已经单独准备的 ARM32 SO 替换进 APK，执行签名与内容检查 | 构建历史通过；补齐 HWID 后真机仍 528 |
| `build_login_ui_v2_candidate_20261016.py` | 构建登录按钮 UI 实验 APK | 打包/签名历史通过，真实完整登录未验证 |
| `patch_firedac_charset.py` | Windows EXE 数据库字符集参数名有限修补 | 隔离 Wine 历史回归有改善，不能作为通用补丁 |
| `build_verify_registration_button_candidate.py` | ARM32 登录按钮 hook 的静态生成/核查 | 静态核查通过，真机验收未覆盖 |

脚本依赖未上传的第三方二进制、隔离工作目录、证据 JSON、签名工具及受限的签名凭据。脚本中的签名文件**路径**不是凭据，仓库内没有签名密钥或密码内容。

不要通过临时删除用户认证检查、绕开审批或向公网上传原有专有游戏文件来让 CI 变绿。
